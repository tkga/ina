# ระบบจัดการร้านโปเกมอน

เว็บจัดการออเดอร์ สต็อก ลูกค้า ไอดีเกม และการเงิน โดยเก็บข้อมูลใน **Google Sheets** ของคุณเอง
มีปุ่ม **Backup** (ดาวน์โหลดเป็น .xlsx / .json) และ **Restore** (นำไฟล์กลับมาใส่ได้ทุกเมื่อ)

เทคโนโลยี: Next.js + Google Sheets API ล็อกอินด้วยรหัสผ่านเดียว (สำหรับเจ้าของร้านคนเดียว)

## 1) เตรียม Google Sheet

1. เปิด Google Sheet เดิมของร้าน ตรวจว่ามี **5 แท็บ ชื่อตรงตามนี้เป๊ะ**: `Orders`, `Customers`, `Accounts`, `Stock`, `Finance`
   และแถวแรกของแต่ละแท็บเป็นหัวคอลัมน์เดิม (ตรงกับไฟล์ Excel ที่ให้มา)
   *ถ้ายังไม่มี Sheet: สร้าง Google Sheet เปล่า แล้วหลังเว็บใช้งานได้ ไปหน้า Backup / Restore เลือกไฟล์ Excel เดิม ระบบจะสร้างแท็บและใส่ข้อมูลให้*
2. คัดลอก **Sheet ID** จาก URL: `https://docs.google.com/spreadsheets/d/` **SHEET_ID** `/edit`

## 2) สร้าง Service Account (ให้เว็บเข้า Sheet ได้)

1. เข้า https://console.cloud.google.com แล้วสร้างโปรเจกต์ใหม่ (ตั้งชื่ออะไรก็ได้)
2. เมนู **APIs & Services > Library** ค้นหา **Google Sheets API** แล้วกด **Enable**
3. เมนู **APIs & Services > Credentials** เลือก **Create credentials > Service account** ตั้งชื่อแล้วกด Done
4. กดเข้า Service account ที่สร้าง ไปแท็บ **Keys** เลือก **Add key > Create new key > JSON** จะได้ไฟล์ .json (เก็บเป็นความลับ ห้ามอัปขึ้น GitHub)
5. ในไฟล์ JSON ใช้ 2 ค่า: `client_email` และ `private_key`
6. กลับไปที่ Google Sheet กดปุ่ม **Share** วางอีเมล `client_email` ให้สิทธิ์ **Editor** แล้วกด Send

## 3) ทดสอบในเครื่อง (ไม่บังคับ)

```bash
npm install
cp .env.example .env.local     # แล้วแก้ค่าในไฟล์
npm run dev                    # เปิด http://localhost:3000
```
อยากลองโดยยังไม่ต่อ Google: ใส่ `STORE=file` ใน `.env.local` (เก็บข้อมูลที่ `data/store.json` ใช้ทดสอบเท่านั้น ใช้ไม่ได้บน Vercel)

## 4) อัปขึ้น GitHub และ Vercel

1. สร้าง repository ใหม่บน GitHub (ตั้งเป็น **Private** จะปลอดภัยกว่า) แล้วอัปโค้ดทั้งโฟลเดอร์ขึ้นไป
   ไฟล์ `.env.local` และ `data/*.json` ถูกกันไว้ใน `.gitignore` แล้ว
2. เข้า https://vercel.com เลือก **Add New > Project** แล้วเลือก repository นี้ (Framework จะเป็น Next.js อัตโนมัติ)
3. ก่อนกด Deploy ไปที่ **Environment Variables** แล้วใส่ 5 ตัวนี้:

| ชื่อ | ค่า |
|---|---|
| `APP_PASSWORD` | รหัสผ่านที่ใช้เข้าเว็บ (ยาว เดายาก) |
| `SESSION_SECRET` | สตริงสุ่มยาวกว่า 32 ตัวอักษร (สร้างด้วย `openssl rand -base64 32`) |
| `GOOGLE_SHEET_ID` | Sheet ID จากข้อ 1 |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | `client_email` จากไฟล์ JSON |
| `GOOGLE_PRIVATE_KEY` | `private_key` จากไฟล์ JSON ทั้งก้อน (รวม `-----BEGIN…END-----` และเครื่องหมาย `\n`) |

4. กด **Deploy** แล้วเปิดเว็บด้วยรหัสผ่านที่ตั้งไว้ (ถ้าแก้ Environment Variables ทีหลัง ต้อง Redeploy)

## วิธีใช้งานสำคัญ

- **Backup:** เมนู Backup / Restore แล้วดาวน์โหลด Excel หรือ .json ควรทำทุกสัปดาห์และเก็บไว้ที่อื่นด้วย
  (หน้านี้เตือนเมื่อเครื่องนี้ไม่ได้ดาวน์โหลดเกิน 7 วัน)
- **Restore:** เลือกไฟล์ ระบบตรวจไฟล์และแสดงจำนวนแถวเทียบกันก่อน เลือกชีตที่จะเขียนทับ แล้วยืนยัน
  ระบบจะดาวน์โหลดข้อมูลปัจจุบันเก็บในเครื่องให้อัตโนมัติก่อนเขียนทับทุกครั้ง
- Google Sheets มีประวัติเวอร์ชันในตัว (File > Version history) ใช้ร่วมกับ Backup ของเว็บเป็นชั้นที่สองได้

## กติกาของข้อมูล

- **ยอดใช้จ่ายสะสมของลูกค้า** = ผลรวม "ชำระแล้ว" ของออเดอร์ที่ไม่ยกเลิก (นับตามชื่อลูกค้า)
- **จำนวนชนิดและคงเหลือรวมของไอดี** คำนวณจากหน้าสต็อกตามชื่อไอดี
  ทั้งสองค่าเว็บเขียนกลับลงชีตให้เองทุกครั้งที่แก้ออเดอร์/สต็อก
- ออเดอร์ลบไม่ได้ ใช้ **ยกเลิก** แทน เพื่อให้ตรวจย้อนหลังได้ และการยกเลิกไม่คืนสต็อกอัตโนมัติ
- ถ้าแก้ชีตตรง ๆ ใน Google Sheets ให้ **ไม่เปลี่ยนชื่อแท็บ ลำดับ หรือหัวคอลัมน์** ไม่เช่นนั้นเว็บจะอ่านผิด
- รูปสินค้าใช้ลิงก์ Google Drive เดิม ไฟล์รูปต้องแชร์เป็น **"ทุกคนที่มีลิงก์"** เว็บจึงจะแสดงรูปได้

## ข้อจำกัดที่ควรรู้

- Google Sheets เขียนได้ประมาณ 60 ครั้ง/นาที เหมาะกับคนเดียวหรือไม่กี่คน
  เว็บตรวจความขัดแย้งให้: ถ้าแถวนั้นถูกแก้จากที่อื่นไปแล้วจะไม่เขียนทับเงียบ ๆ แต่ให้โหลดใหม่
- ล็อกอินล็อกชั่วคราวเมื่อใส่รหัสผิด 5 ครั้ง (นับในหน่วยความจำของเซิร์ฟเวอร์ ไม่ใช่ระบบกันบอทเต็มรูปแบบ)
